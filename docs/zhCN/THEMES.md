# 认证主题

原生主题需要包含此功能的 Stargate 构建；旧版本不会读取这些设置。
主题格式和 UI 协议版本均为 `1`。

通过 `THEME_DIR=/app/themes/deep-space` 选择一个主题目录。在 Docker 中将
主题目录只读挂载到该路径，并确保 UID 10001 可以读取文件、遍历目录。
主题在启动时校验并读入内存；修改后需要重启。显式选择的主题无效时启动失败。

`THEME_SAFE_MODE=true` 跳过主题及旧的模板、静态资源和 favicon 覆盖，使用
内置界面。即使主题目录损坏或不可读，也可以通过该设置恢复服务。

启用主题时，登录、账号管理、TOTP 开始绑定、确认绑定、撤销和二次认证页面
统一使用内置模板与脚本。主题只提供文字、颜色和图片，不参与认证逻辑。
未配置主题且未开启安全模式时，保留原有外部目录优先规则。
根路径、ForwardAuth、认证 API、回调、会话及限流行为不变。

主题目录包含 `theme.yml`、可选的 `assets/<图片>` 和 `LICENSE.txt`。
不接受 CSS、HTML、JavaScript、字体、SVG、符号链接或其他额外文件。
主题文件最多 64 KiB；图片仅支持 PNG/JPEG，最多 2 MiB、单边 8192 像素、
总计 3200 万像素。文件扩展名必须与图片头匹配，不校验完整图片数据。

清单必填字段为 `contract`、`ui_contract`、`id`、`name`、`version`、`author`、
`license`、`layout`。布局支持 `split` 和 `centered`；分栏在 900px 以下堆叠。
`tokens` 配置颜色、圆角和字号比例；颜色仅接受带引号的 `#RRGGBB`，
圆角为 `0px` 至 `32px` 的整数，字号比例为 0.8 至 1.5，最多四个字符。
文字、辅助文字、链接、错误提示与背景及卡片的对比度至少为 4.5:1；
按钮文字与按钮背景、品牌文字与品牌底色也必须达到 4.5:1。焦点颜色与背景及卡片至少为 3:1。
图片区域仍需要人工检查可读性。

`modes.light`、`modes.dark` 可覆盖基础变量，跟随设备配色偏好；未声明时保持
固定配色。每种配色都校验对比度。`brand` 支持 `image`、`heading`、`caption`、
`eyebrow`，文字为经过 HTML 转义的纯文本，每项最多 256 字节，不含换行或 NUL。
品牌装饰文字不随语言变化。站点标题、页脚、求助链接仍由现有部署配置控制，
认证表单沿用七种语言。

资源地址包含清单、生成的样式表和图片内容的 SHA-256，使用固定 MIME、`nosniff` 和不可变缓存。
清单及许可证不对外提供。认证 HTML 保持 `no-store` 和原有 CSP。
运行时不重新读取目录，不下载或自动更新主题。加载期间目录应由管理员控制。
每个进程只提供当前摘要的资源；多副本应部署一致的主题。重启后，尚未加载旧
资源的页面可能需要刷新。

在 Stargate 源码目录执行：

```sh
go run ./src/cmd/themecheck /path/to/deep-space
```

退出码为：`0` 校验通过，`1` 存在无效主题，`2` 未提供参数。
校验器与服务使用相同加载逻辑，不发起网络请求。应使用实际部署版本运行校验。

主题单独维护于 <https://github.com/soulteary/stargate-themes>。下载发行包后先解压，
再挂载目录；服务不直接加载 ZIP。完整字段、示例及限制见
[英文主题协议](../enUS/THEMES.md)。
